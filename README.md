# Degree or Certificate? — інтерактивна презентація (ENG HUB)

Студент вводить ім'я й проходить слайди на своєму пристрої. Викладач в адмінці бачить загальну картину, а імена відкриває кліком.

| Слайд у презентації | Слайд PDF | Що робить студент | Що видно іншим студентам |
|---|---|---|---|
| This or That | 2 | обирає варіант у 7 парах | нічого |
| The Employability Budget | 3 | ділить 100 балів між 6 пунктами, натискає **Submit** | нічого |
| Our group’s priorities | — (новий) | бачить рейтинг групи (середні бали) і свою позначку | лише анонімний підсумок, **без імен** |
| Make the Case | 8 | обирає вирази, твердження, позицію for/against; є 30-секундний таймер | нічого |
| The £10K Education Challenge | 9 | перевертає картки, збирає план до £10,000 | нічого |

Навігація: кнопки ← / Next →, крапки внизу або стрілки на клавіатурі. Слайд з рейтингом відкривається тільки після того, як студент надіслав свій бюджет, і оновлюється кожні 5 секунд.

| Файл | Що це |
|---|---|
| `index.html` | презентація для студентів |
| `admin.html` | адмінка: вкладки по кожному слайду, CSV, очищення |
| `config.js` | **єдиний файл, який треба правити**: ключі Supabase і всі тексти слайдів |
| `supabase/schema.sql` | таблиці й функції для Supabase (виконати один раз) |
| `api.js`, `styles.css`, `img/`, `fonts/` | службові файли |

## 1. Бекенд (Supabase, ~5 хв)

1. Увійдіть у Supabase під потрібним акаунтом і створіть проєкт (**New project**). Регіон: Frankfurt або найближчий.
2. **SQL Editor → New query**. Вставте весь вміст `supabase/schema.sql`.
   В останньому рядку замініть `change-me` на свій пароль для адмінки й натисніть **Run**.
3. **Project Settings → API Keys** (або кнопка **Connect**). Скопіюйте:
   - **Project URL** (`https://xxxx.supabase.co`)
   - **Publishable key** (або legacy **anon public**). ⚠️ Не `service_role` і не `secret`!
4. Впишіть їх у `config.js` → `SUPABASE_URL` і `SUPABASE_KEY`.

Ключ publishable/anon можна класти в публічний репозиторій. Таблиці закриті, і браузер може тільки:
зберегти свою відповідь, отримати анонімний рейтинг бюджету, а з паролем — прочитати все чи очистити (адмінка).

Змінити пароль адмінки потім: у SQL Editor виконайте
`update app_settings set value = 'новий-пароль' where key = 'admin_key';`

> Безкоштовний проєкт Supabase засинає після 7 днів без активності. Перед заняттям відкрийте дашборд і натисніть **Restore**, якщо проєкт на паузі.

## 2. GitHub Pages

1. Закиньте всю папку в репозиторій.
2. **Settings → Pages → Deploy from a branch → main / root**.
3. Студентам: https://villevian.github.io/neo-team-SC/
   Адмінка: https://villevian.github.io/neo-team-SC/admin.html (запитає пароль з кроку 1.2).

## Адмінка

- Вкладки: **This or That · Employability Budget · Make the Case · £10K Challenge**, у кожній лічильник «відповіли / всього».
- За замовчуванням видно тільки загальну картину. **Клік по рядку** відкриває, хто що обрав. «Розгорнути всі імена» відкриває все одразу.
- Під кожною вкладкою є кнопка «Таблиця по студентах».
- Автооновлення кожні 4 с, **CSV** (усі відповіді одним файлом), **Очистити все** перед новою групою.

## Демо без бекенду

Поки `SUPABASE_URL`/`SUPABASE_KEY` порожні, усе працює в демо-режимі (лише в цьому браузері). Запустіть `python3 -m http.server` у папці, відкрийте `http://localhost:8000` і `http://localhost:8000/admin.html` у двох вкладках.

## Змінити тексти

Усі тексти (пари, пункти бюджету, вирази й тлумачення, твердження, картки £10K) лежать у `config.js`. `id` краще не міняти посеред заняття, бо по них зберігаються відповіді.
